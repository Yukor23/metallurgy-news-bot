# Metallurgy News Bot

Telegram-бот, который присылает новости металлургии России. Без сервера:
всё выполняется по расписанию в GitHub Actions (бесплатно), данные хранятся
прямо в репозитории.

## Как это работает

- Каждые 20 минут GitHub Actions запускает `bot.py`.
- Скрипт опрашивает источники из [feeds.py](feeds.py), находит новые
  материалы, сохраняет их в `data/articles.json` (архив на 60 дней).
- Отвечает на команды пользователей (`/news`, `/start`, `/stop`).
- Один раз в день, в первый запуск после 08:00 по Москве, рассылает
  утреннюю сводку всем подписчикам.
- Изменённые файлы из `data/` коммитятся обратно в репозиторий тем же
  workflow-шагом — так между запусками ничего не теряется.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Подписаться на утреннюю сводку |
| `/stop` | Отписаться |
| `/news` | Новости за сегодня |
| `/news 3` | Новости за 3 дня |
| `/news неделя` | Новости за неделю |
| `/help` | Справка |

## Настройка (шаги)

1. **Создать бота.** В Telegram откройте `@BotFather` → `/newbot`,
   задайте имя и username. Сохраните токен — он понадобится на шаге 4.

2. **Создать репозиторий на GitHub.** Публичный репозиторий даёт
   безлимитные бесплатные минуты Actions (у приватных — 2000 мин/мес,
   при опросе каждые 20 минут этого может не хватить). Код бота не
   содержит токена и секретов, так что публичный репозиторий безопасен.

3. **Залить код.** В папке `metallurgy_news_bot/`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-username>/<repo>.git
   git push -u origin main
   ```

4. **Добавить токен как секрет.** В репозитории на GitHub:
   Settings → Secrets and variables → Actions → New repository secret →
   имя `TELEGRAM_BOT_TOKEN`, значение — токен от BotFather.

5. **Запустить вручную и проверить.** Вкладка Actions → workflow
   "Metallurgy News Bot" → Run workflow. Затем напишите своему боту
   `/start` в Telegram — придёт подтверждение подписки.

6. Дальше всё работает само: сбор новостей и рассылка — по расписанию,
   без вашего участия.

## Настройка под себя

- Список источников — [feeds.py](feeds.py). Можно добавлять/убирать
  ленты, менять поисковые запросы Google News.
- Час утренней сводки — `DIGEST_HOUR` в [bot.py](bot.py) (по умолчанию 8,
  время московское).
- Частота опроса — `cron` в
  [.github/workflows/news-bot.yml](.github/workflows/news-bot.yml)
  (по умолчанию каждые 20 минут; GitHub может по своему усмотрению
  задерживать запуск при высокой нагрузке).

## Дальнейшие шаги (по плану)

Следующий этап — умная сводка: разметка новостей тегами «критично»,
«важно», «влияние на компанию», «цены», «регулирование» и короткая
выжимка по каждой важной новости. Это добавляется в `bot.py` как шаг
обработки перед отправкой, с вызовом LLM — начнём, когда будет готова
базовая доставка.
